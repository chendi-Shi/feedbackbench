# 相关工作与本项目边界

FeedbackBench 的历史调度研究检验固定重规划间隔、图像/夹爪变化触发及时间集成如何改变成功率和推理预算，已完成的四个 MINERVA 阶段共 232 回合，另 16 个原计划回合未尝试；见 [历史协议](PROTOCOL.md) 与 [基线结果](BASELINE_RESULTS.md)。当前主线是 [ActionCache–SmolVLA 独立迁移研究](CACHE_PROTOCOL.md)。两项研究均使用同步 LIBERO 控制循环，仿真在 Python 推理期间不会继续推进；实际结果按各自冻结协议和原始回合记录解释，不合并为同一方法或模型的成功率。

**ActionCache（2026，作者论文 v2）。** 该工作的动机是通过多模态上下文检索可复用的动作生成状态，再用少量采样步骤细化。我们据此独立实现 SmolVLA 推理迁移，比较完整十步、纯噪声两步、缓存中间 latent 后两步细化，以及直接复用最终动作。与论文的在线缓存设置不同，本项目只从成功开发回合准入样本，随后冻结缓存，测试不更新或淘汰条目；阈值固定为 0.95，未据测试结果调优。我们未使用作者实现，也未复现论文原模型与在线 LRU 策略。2026 指方法文献年份，不表示所用 SmolVLA 检查点是当前 SOTA，更不代表已在 π 或 GR00T 上实测。研究检验的是这种离线迁移下的成功率与实际计算成本，不预设缓存能够保持成功或带来有效加速。[作者论文 v2，2026-08-03](https://arxiv.org/html/2607.06370v2)

**Adaptive Action Chunking at Inference-time for Vision-Language-Action Models（AAC，CVPR 2026）。** AAC 从同一观测并行采样多个候选动作块，估计连续动作与夹爪动作的熵，再根据不同执行长度下平均熵的变化选择分块长度，并设定长度下界。旧调度实验直接比较当前观测与上次推理时的图像/夹爪状态，不估计动作熵，也未实现 AAC 的采样和长度选择算法。因此，该实验不是 AAC 论文复现；“依据反馈调整执行长度”的思路已有明确先例。若未来增加 AAC 对照，额外采样成本必须计入推理预算，而不能只统计调度请求次数。[论文正文，第 3.2–4 节](https://arxiv.org/html/2604.04161v2)

**Real-Time Execution of Action Chunking Flow Policies（RTC，NeurIPS 2025）。** RTC 让新动作块的生成与旧动作块的执行重叠，在推理期间冻结必然执行的动作，并通过 inpainting 生成其余动作，以维持跨块一致性；论文同时评估动态仿真和真实双臂任务。本项目采用同步调用，未实现并发执行、推理延迟下的已提交动作前缀或 inpainting。人为延迟四步观测只检验陈旧输入下的控制行为，不能等同于 RTC 的实时计算延迟实验，也不能据此声称复现了其吞吐或真机鲁棒性。[作者发布的论文](https://www.physicalintelligence.company/download/real_time_chunking.pdf)

**Asynchronous Robot Inference: Decoupling Action Prediction and Execution（Hugging Face / LeRobot，2025）。** 官方实现将策略服务与机器人客户端分开，让客户端消耗动作队列的同时接收新预测；队列阈值控制请求时机，服务端还用关节空间相似性过滤冗余观测。本项目没有客户端/服务端并发或网络控制，图像/夹爪变化门控也不能声称首次利用状态变化节省推理。二者共同关注反馈与计算成本，但本项目测量的是同步执行中的调度频率与任务表现，不能借用官方异步系统的加速结果。[官方技术说明](https://huggingface.co/blog/async-robot-inference)

本项目可以形成研究与求职价值的部分，是明确假设、固定检查点和环境、开发/测试分离、跨任务配对、成本分解、方法消融、失败分析及可复现产物。MINERVA 应表述为任务 ID 条件化视觉动作策略，不能称为 VLA；SmolVLA 也只支持本项目实际测试过的任务与初态结论。已有方法的系统复现或可靠负结果值得展示，但需要与算法创新、全基准复现和真机验证分别说明。
