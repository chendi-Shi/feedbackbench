# VLA-JEPA 每回合独立进程：四任务完整可行性协议

本协议在首次执行前冻结。上一 [compact 阶段](VLAJEPA_COMPACT_PROTOCOL.md) 已完成并封存前三个任务，但切换到第四个环境、尚未执行其动作时，自身 RSS 达 5,962,772,480 字节，超过固定 5.5 GiB 上限，保护退出。当前问题是：每个回合从新进程开始，避免前序任务留下的 allocator 与渲染状态，能否在相同资源保护下完成四个任务？这是假设，不预设能完成，也不把前次中止归因于已证明的内存泄漏。

新入口 `scripts/run_vlajepa_isolated.py`，独立目录 `outputs/frontier/vlajepa_isolated_closed_loop`，case model `vlajepa_isolated`。原阶段所有成功、失败、中止与未封存目录完整保留；不移动、复制或重新封存其前三个成功结果为本阶段结果。**本阶段重新执行完整四回合，只有自身四个回合全封存且严格校验通过，才称此协议完成。** 不将前阶段的三次成功或其资源中止隐藏在新分母外。

## 保持不变的内容

沿用 [compact 协议](VLAJEPA_COMPACT_PROTOCOL.md) 的模型与环境：相同官方来源、checkpoint、处理器、300 个动态 INT8 Linear、完整 BF16 分页 embedding 与 FP32 动作头，4 步 flow、7 步动作块；256 MiB MuJoCo arena、nconmax=5000，其他场景 XML 和图像参数不变。沿用真实单观测动作逐值一致及 978 步四套件环境重放门槛，执行前再次检查来源与保存数组/图像。

固定顺序 spatial/object/goal/libero_10，各 task 1、init state 41、seed 1000，时限 280/280/300/520 控制步。360×360 双相机、8 维机器人自身状态及真实文本输入；固定 20 Hz 相对 OSC、hard reset 与 10 步 settle；无额外预热、训练、控制兜底或物体状态泄漏。两个 CPU 计算线程、一个 inter-op 线程。推理时暂停仿真，不表示实时控制。

导入前和加载前系统可用内存至少 3.5 GiB；运行时自身 RSS 上限 5.5 GiB、系统可用内存下限 0.5 GiB，每秒采样。阈值不放宽，也不停止或调整其他项目。3.5 GiB 仅为探索性启动预算，不是已证实硬件最低配置；采样保护不能保证捕获所有瞬时峰值。

## 独立进程执行与账本

`freeze` 固定完整四回合与 22 个执行相关源码文件。每次从新的 Python 进程调用 `run-one`，重新构造、校验并加载同一模型，最多执行一个尚未开始的回合；正常结束后进程退出，下一回合由下一次命令在新进程执行。禁止在同一常驻 Python 进程反复调用入口。模型加载开销逐进程记录，不能从测量中隐藏，也不能把本阶段耗时与原常驻模型阶段直接相除称加速。

执行顺序固定，已完整封存的回合只读校验后跳过；所有未开始回合仍由同一个四回合冻结协议定义。每个 worker 记录自身进程身份、开始/结束与执行前后完成数，形成可核验的隔离账本。每次 CLI 串行完成才启动下一次，不并发加载多个模型或环境。权重加载前的资源阻断如未创建任何回合，可在资源满足后继续并保留阻断记录；部分、错误或未封存回合不自动覆盖重跑。

继承所有逐规划动作、实际初始噪声、RNG、当前观察指纹、实际 300 模块覆盖、4 次动作头求值，以及逐步执行动作与状态、图像、视频、结果和 SHA receipt。继承 arena 初始化编译审计和 reset/逐步容量、警告检查。JSON 临时 PermissionError 使用有界写入重试，补足 receipt 封存函数的独立写入绑定；不重试机器人动作或模型推理。

对与上一阶段重叠的前三个任务，可额外比较初始状态/双相机、首个调用的 RNG、初始噪声和模型/环境动作，并比较保存轨迹；这是一致性诊断，需报告实测是否相等，不预设结果或用不相等筛掉回合。无新推理，也不形成额外成功率分母。

如果原生 warning 被底层 reset 重试逻辑持续吞掉，可能无法返回外层检查。本阶段没有宣称重写该上游行为；出现持续初始化无进展时应保留记录、仅终止本实验子进程，并记录运行中止，不能跳过警告后封存。正常返回时所有原生 warning 与 8 项计数仍必须为零。

## 结果解释

`report` 可以生成未完成状态，`validate` 只有自身四个回合均完整才通过。运行完成与任务成功分别统计；达到时限而未成功才是任务失败，内存中止和未开始不算任务失败。完整阶段报告每个任务的官方成功、步数、规划次数、NFE、延迟与各进程内存/加载开销；不把 replay 或测试加入分母。

这是四个已知初态上的本机可行性评测，不是完整 LIBERO、SOTA、未见任务泛化、BF16 质量保持或真机结论。先前 owned 四次阻断、paged 一次初始化中止、compact 三成功加一次初始化中止均单独展示。进程隔离若完成，仅支持该轮在当时共享主机条件下的执行可行性；不证明持续稳定运行或 arena 容量改变节省了物理 RSS。
